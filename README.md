# Shout Chat

A chat model that shouts your message back in capital letters.

> A test plugin for [dashAI](https://github.com/DashAISoftware/DashAI), installed by its repo link or a local `.zip`. It is not in the plugin store.

## Components

| Class | Type |
| --- | --- |
| `ShoutChatTask` | GenerativeTask |
| `ShoutModel` | GenerativeModel |

## Usage

In **Generative**, choose the **Shout chat (plugin)** task and the **Shout (plugin)** model. Write anything.

## Details

- **Requires:** dashAI 0.10.0 or newer.
- **Dependencies:** none.
- **Releases:** Releases are built and signed by this repo's GitHub Actions workflow (`.github/workflows/release.yaml`): dashAI shows them as verified.
